# README imagery

`notch-hero.png` is a product illustration generated with built-in ImageGen from a reference of Clip's native interface. It shows the closed and expanded notch in a macOS menu bar. It is an illustration rather than an unedited app screenshot. Private habit controls are omitted.

The generation prompt is in `notch-hero.prompt.txt`. No user screenshot, local settings or credentials are included here. The original SVG Draw-flow illustration remains available as `draw-flow.svg`.
